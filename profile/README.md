# ALICE

Building a modular ecosystem for productivity, collaboration and intelligent automation.

> One platform.
> Multiple applications.
> Designed to work together.


## What is ALICE?

ALICE is a modular software ecosystem designed to provide a unified experience across productivity, communication, AI and business applications.

Every application can work independently or integrate seamlessly through Cardinal, the central orchestration platform.

# 🗺️ ALICE Roadmap

This roadmap outlines the long-term vision of the **ALICE** ecosystem. Development follows a modular approach, where each project provides standalone value while integrating seamlessly through **Cardinal**, the central orchestration platform.

> **Vision:** Build a unified ecosystem for business management, collaboration, artificial intelligence, and smart devices.

---

## Development Strategy

Instead of developing every project simultaneously, ALICE is built in incremental phases.

Each phase introduces new capabilities while strengthening the overall ecosystem.

---

# Phase 1 — Foundation

Establish the core infrastructure shared by every application.

### Light-Cube

**Identity & Access Management**

* User management
* Organizations
* Roles & permissions
* Authentication
* API authentication
* Multi-factor authentication (future)

**Status:** 🚧 In Development

---

### Cardinal

**Central Orchestration Platform**

Acts as the entry point of the entire ALICE ecosystem.

Core responsibilities:

* Application launcher
* Dashboard
* Notifications
* Module management
* Central configuration
* API Gateway
* Integration layer

**Status:** 📋 Planned <!-- 🚧 In Development -->

---

## Phase 2 — Underworld

Deliver the first commercial product built on top of Cardinal.

Modules may include:

* CRM
* Customer Management
* Quotations
* Invoicing
* Documents
* Ticketing
* Inventory *(future)*
* Finance *(future)*

**Status:** 📋 Planned <!-- 🚧 In Development -->

---

## Phase 3 — Yui

### AI Assistant

Yui brings intelligent automation across the ecosystem.

Examples:

* Generate documents
* Summarize meetings
* Search business data
* Execute workflows
* Assist users across every module

Yui becomes more capable as additional modules are introduced.

**Status:** 📋 Planned

---

## Phase 4 — Ordinal Scale

### Communication Platform

Enterprise messaging and collaboration.

Features:

* Direct messages
* Team channels
* Voice & video calls
* File sharing
* AI-assisted conversations
* Deep integration with Cardinal and Yui

**Status:** 📋 Planned

---

## Phase 5 — Augma-OS

### Smart Glasses Operating System

A lightweight operating system designed for wearable devices.

Possible features:

* Low-latency interface
* AI integration
* Hands-free interaction
* Remote management through Cardinal

**Status:** 💡 Concept

---

## Phase 6 — Aincrad

### Secure Operating System

A lightweight desktop operating system focused on:

* Security
* Performance
* Privacy
* Enterprise deployment

Optional integration with Cardinal enables centralized management.

**Status:** 💡 Concept

## Long-Term Goal

Create a complete ecosystem where every application can operate independently while becoming significantly more powerful when connected through **Cardinal**, providing users with a unified and intelligent platform.


## Philosophy

ALICE is built around a few core principles:

- Modular by design
- API-first
- Privacy focused
- Lightweight
- Cross-platform
- AI-assisted workflows
- Open integration
